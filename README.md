# The Way of Becoming

[![CI](https://github.com/ArbitraryConstant/philosophical-adventure/actions/workflows/ci.yml/badge.svg)](https://github.com/ArbitraryConstant/philosophical-adventure/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-8b4513.svg)](LICENSE)

**A choose-your-own-adventure through Deleuzean and Daoist philosophy, written as you go by Claude.**

**Play it at [thewayofbecoming.org](https://www.thewayofbecoming.org).**

![The Way of Becoming](public/og-image.jpg)

Each journey is a new story. At every step you read a short, contemplative scene, see the concept it explores (a rhizome, wu wei, a line of flight, the Dao), and choose one of four ways forward. No two journeys are the same.

## Features

- **A story written for you** - every scene is generated by Claude in response to your choices
- **Twenty parts** - a journey runs up to 20 scenes, and the last one is an ending
- **Pick up where you left off** - your journey is remembered in your browser if you close the tab
- **Save your story** - download it at any point as plain text, Markdown, a web page, or a PDF
- **Your path** - a running list of every choice you have made

## How it works

```
Browser (public/)                Server (server.js, src/)             Claude API
-----------------                ------------------------             ----------
the journey so far   --POST-->   checks the request,
                                 adds the story prompt     --------->  writes the next scene
story, concept,      <--JSON--   reads the reply into
four choices                     story / concept / choices <---------
```

- The browser sends only the journey so far: the scenes and the choices made.
- The server holds the story prompt and the API key. Visitors never see either.
- Claude replies in a simple labelled format, which the server reads tolerantly and checks before passing it on.
- Prompt caching keeps the cost of re-sending a growing story low.
- To limit misuse and cost, the server caps the journey length, the size of each request, and the number of requests per visitor.

## Running it locally

You need [Node.js](https://nodejs.org) 22 or newer and an [Anthropic API key](https://console.anthropic.com/).

```powershell
npm install

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "your-api-key-here"

npm start
```

Then open <http://localhost:3000>.

On macOS or Linux, set the key with `export ANTHROPIC_API_KEY="your-api-key-here"` instead.

### Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | Yes | Your Anthropic API key |
| `CLAUDE_MODEL` | No | The Claude model to use (default: `claude-sonnet-5-5`) |
| `PORT` | No | The port to listen on (default: `3000`; hosting platforms set this themselves) |

### Tests

```powershell
npm test       # run the automated tests
npm run lint   # check code style
```

The tests never contact Anthropic and need no API key.

## Deployment

The live site runs on [Railway](https://railway.app), deployed from this repository. **Pushing to the `main` branch redeploys the live site.**

To deploy your own copy: create a Railway project from the repository, add the `ANTHROPIC_API_KEY` variable, and Railway does the rest. A healthy deploy log shows:

```
Server running on port ... (model: claude-sonnet-5-5)
```

Each scene also writes a line to the log showing how many tokens it used and how much of the story was read from the cache.

### A warning about editing files on Windows

Do not save `package.json` or other project files with Windows PowerShell's `Set-Content -Encoding UTF8` or `Out-File`. They add an invisible marker (a "BOM") to the start of the file. In `package.json` this stops Railway recognising the project as a Node.js app, and the site goes down. Use an editor such as VS Code or Notepad instead. `npm test` checks for this.
